# Visão futura do Olli

## Tese

Olli começa como ferramenta de orçamento, mas pode evoluir para o **sistema operacional do prestador de serviço**.

A lógica de expansão:

1. **Olli Trabalha** — orçamento, OS, clientes, agenda, documentos.
2. **Olli Vende** — follow-up, WhatsApp, páginas, leads, IA comercial.
3. **Olli Opera** — equipe, agenda, recorrência, manutenção, materiais.
4. **Olli Conecta** — rede de prestadores e repasse de serviços.
5. **Olli Marketplace** — cliente, prestador, fornecedor, materiais e parceiros.
6. **Olli Ecossistema** — pagamentos, crédito, seguros, inteligência e serviços financeiros.

## Regra de expansão

Cada nova função precisa melhorar pelo menos uma destas métricas:

- aquisição;
- ativação;
- conversão;
- retenção;
- ticket médio;
- efeito de rede;
- redução de churn.

## Visão de longo prazo

O prestador deveria conseguir:

- receber um cliente;
- transformar áudio em orçamento;
- enviar pelo WhatsApp;
- receber aprovação;
- criar OS;
- organizar agenda;
- cobrar;
- comprar material;
- achar parceiro;
- repassar serviço;
- contratar mão de obra;
- receber novos clientes;
- medir lucro;
- operar tudo dentro do Olli.
