# Central de pesquisas do OLLI Orçamentos

Atualizado em: 30/08/2026

Esta pasta é o ponto de entrada para pesquisas de produto, experiência, concorrência, adoção, acessibilidade, motion, performance e integrações relacionadas ao OLLI Orçamentos.

## Regra de organização

- Estudos antigos permanecem em seus caminhos originais para não quebrar referências, histórico ou evidências.
- Cada nova rodada ganha uma pasta datada e um inventário de reuso.
- Fatos, inferências, hipóteses e resultados de campo devem permanecer separados.
- Pesquisa pública em sites, lojas e fóruns não equivale a entrevista nem validação de mercado.
- Nenhuma credencial, sessão, dado de cliente, conteúdo de grupo fechado ou segredo deve ser guardado aqui.
